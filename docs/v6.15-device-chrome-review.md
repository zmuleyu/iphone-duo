## Verified differences and bounded fixes

1. Closed and Open now have independent system-UI states. Closed defaults to a clean image (`off`); Open defaults to the lock-screen UI (`on`). Both remain directly switchable in Setup and through query/debug controls.
2. Date/time and Wi-Fi still come from the prepared Apple `clock-inner.avif` / `clock-outer.avif` overlays. Clock size (70–105%, default 78%) and vertical position (-4–10%, default 2%) are now directly adjustable without moving Wi-Fi.
3. Flashlight and camera use the same white-ring, monochrome icon language as Wi-Fi instead of the former beige filled controls. The home indicator remains a clean white line.
4. The upper right-rail key remains at the reviewed `+0.04x`; the lower key returns to `0.00x` so it does not float outside the rail. The two top caps use the same Apple-authored `0.00` transform, preserving a clear, aligned protrusion rather than flattening them.
5. Hinge, panels, Screen UV, fixed camera, fold motion and frame clock remain unchanged.

Tokyo Reality/RedBlack assets, reveal logic, montage, birds, tower effects, text and sound are unchanged.
