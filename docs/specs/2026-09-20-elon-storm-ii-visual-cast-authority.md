# Elon STORM II 角色与视觉权威

## 1. 目的

本文档把 `local-archive/source-materials-2026-09-20/马斯克版本` 中仍有效的讨论，连同 2026-09-20 的用户纠正，归档为当前项目的角色、服装、人物关系和关键帧依据。

它不是对旧文档的全文复制。发生冲突时，按以下顺序处理：

1. 用户当前明确决定；
2. 本文档；
3. 当前 Fold Engine 与镜头/时间轴合同；
4. 外部讨论稿与早期角色方案。

## 2. 当前决定

STORM II 的传播吸引力不能被简化为“中心人物加匿名群舞”。当前分支的核心是：

- **Elon 是主锚点、催化者和系统开关**；
- 周围人物是 AI、芯片、平台、航天与科技产业中可被受众迅速识别的热门人物；
- 周围人物不是无名舞者，也不是平等排列的名人墙，而是承担明确语义的反锚点与人物合唱层；
- 折叠过程逐步揭示人物关系，完全展开后才形成可传播的集体画面；
- 服装本身承担人物识别与层级，不得把所有人物统一成黑色健身舞台服；
- 白色或浅色衬衫是 Elon 主视觉的优先方向之一，不能被默认黑 T 恤悄然替代。

`iPhone_Duo_STORM_Fold_Choreography_Plan_v4.md` 中“虚构原型人物作为生产基线”的决定，已被本次用户决定覆盖。它仍可提供折叠、队形和单次 Pulse 的工程参考，但不再拥有当前角色选型权威。

单个 0.3 秒社交媒体缩略图中，保留 3–4 名清晰可读人物。人物不等权：

| 主锚点 | Elon Musk | 主角、催化者、system switch | 发型、侧脸/三分之四角度、略克制或略笨拙的站姿、浅色衬衫形成的中心明度 |

## 4. 中心人物与周围人物的关系

### Closed / teaser

- Elon 单独或主要可见，位于右侧三分之一或被外屏裁切；
- 只暴露一个世界线索，不提前展示完整人物阵容；
- 点烟/点火、回头或轻微转身属于可选叙事动作，正式采用前需单独确认平台、表达和人物权利边界。

### Opening / first reveal

- Elon 向铰链方向移动；
- Jensen 或 Sam 从另一侧首先显现；
- 人物出现由折叠空间驱动，而不是普通横向画面中的入场动画。

### Seated / formation

- Elon 位于前景或视觉中心；
- Jensen 与 Sam 分居后方两侧，构成两个反锚点；
- Dario 或 Gwynne 位于更深一层；
- 人物之间必须形成可读的产业关系，而不是舞团式左右对称站位。

### Landscape / payoff

- 完全展开后执行一次统一 Pulse；
- Elon 面向前方稳定下来，可做一次很小的 conductor downbeat；
- 周围热门人物与系统元素共同响应，但不得抢走主锚点；
- 最终 Freeze 必须同时满足：Elon 第一眼可见、Jensen/Sam 第二眼可认、整体在横屏缩略图中成立。

## 5. 服装权威

### Elon

首选为干净的白色或浅色衬衫配深色长裤：

- 用明度差建立 STORM II 式中心轮廓；
- 保持简洁、无品牌、无领带或复杂配件；
- 剪裁应自然，不做肌肉强化或超级英雄化；
- 袖口、领口和下摆需要在转身、步行与最终 Freeze 中保持稳定。

深色西装或黑色修身造型只保留为备选测试。黑 T 恤不再是默认成片服装。

### 周围人物

- Jensen：受控的黑色皮夹克，作为最高识别度的反锚点；
- Sam：柔和针织或简洁深色上衣，与 Jensen 的硬质轮廓形成对照；
- Dario：低调、深色、研究者气质；
- Gwynne：克制、结构清晰的高管/航天工程语汇；
- 不把所有人物改造成舞者、健身模特、战术服或统一制服。

识别优先级为：轮廓、服装、姿态、眼镜/胡须/发型等编辑式标志，高于照片级脸部复制。

## 7. 当前资产取舍

`elon-storm-ii-dance-keyframes-v2` 中的匿名黑衣舞者方案不再作为正式角色输入：

- **否决**：匿名健身型舞团、统一黑色舞台服、24–36 名无语义人物承担主要传播吸引力；
- **可保留**：群体密度、三层景深、静止—Pulse—Freeze 的运动与构图参考；
- **不得继续**：把这些帧直接提交给多关键帧视频模型并称为 STORM II 正式人物方案。

后续关键帧必须重新建立在本文件的人物与服装权威上。
